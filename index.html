Open Microsoft FormOpen SharePoint Database

The absent-teacher dropdown is populated from teacher names in imported records. The substitute-teacher dropdown filters out the absent teacher and teachers already assigned during the same date and period. For live SharePoint availability, configure the directory endpoint to return JSON such as {"teachers":[{"name":"Teacher Name","busySlots":[{"date":"2026-10-21","period":"8:00–8:50 AM"}]}]}. The SharePoint folder link alone does not grant website read/write access. To enable Save records to SharePoint, an administrator must create a Power Automate flow with an HTTP request trigger and SharePoint Create item actions, then paste the flow URL above. Keep that URL private because it may act as a credential. The button sends the current browser records as JSON to the configured flow; saving is not active until the flow is configured.
